# Frontend

React/TypeScript reviewer for retained CPSC notices. Run `npm ci` and `npm run dev` from this directory. Without `VITE_API_BASE_URL`, the app uses its labelled rules-only local interface demo; model inference is unavailable in that mode. Set `VITE_API_BASE_URL` only when connecting to a separately configured private backend. The UI presents exact retained source text, facts, unknowns and conflicts; a person makes any decision.

The original logo and favicon bitmaps are intentionally omitted from this public snapshot because their separate redistribution terms were not documented. The public copy uses a text mark instead.
